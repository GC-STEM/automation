## Organization Replace Strings

| **Replace String** | **Current Value** | **Description** |
| --- | --- | --- |
| OrgId | {OrgId} | ID number of the organization |
| OrgName | {OrgName} | Name of the organization |
| OrgUnitId | {OrgUnitId} | ID number of the organization unit (i.e., the D2L course); used in course-specific URLs |
| OrgUnitName | {OrgUnitName} | Name of the organization unit |
| OrgUnitCode | {OrgUnitCode} | Code for the organization unit |
| OrgUnitTypeId | {OrgUnitTypeId} | ID number of the type of the organization unit |
| OrgUnitPath | {OrgUnitPath} | Path to files for the organization unit |

## User Replace Strings

| **Replace String** | **Current Value** | **Description** |
| --- | --- | --- |
| UserId | {UserId} | D2L-assigned ID number of the user. Used in user-specific URLs. |
| UserName | {UserName} | D2L username entered to log on |
| OrgDefinedId | {OrgDefinedId} | Organization assigned ID for the user (e.g., student ID number) |
| FirstName | {FirstName} | First name of the logged-in user from their user profile |
| LastName | {LastName} | Last name of the logged-in user from their user profile |
| Email | {Email} | User's primary email address (e.g. @school.edu) |
| ExternalEmail | {ExternalEmail} | User's external to D2L email address; may be the same as Email |
| InternalEmail | {InternalEmail} | User's D2L internal email address (e.g., @d2l.school.edu); may be the same as Email |
| RoleId | {RoleId} | Internal ID number for user's role |
| RoleCode | {RoleCode} | Code for user's role |
| RoleName | {RoleName} | Name of user's role |
